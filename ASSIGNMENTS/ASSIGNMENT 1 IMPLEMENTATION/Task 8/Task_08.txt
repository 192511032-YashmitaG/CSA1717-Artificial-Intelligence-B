TASK 8 – IMPLEMENTATION AND TESTING

Run from the main assignment folder:
python Task_08/Task_08.py

Algorithms implemented: BFS (queue), iterative DFS (stack), recursive depth-limited search inside IDDFS, and uniform-cost search for non-negative weighted travel-time edges.

Test input
1. Generated graph with 40 locations, branching factor 3, start 0, goal 39.
2. Same graph, start 7, goal 7.
3. Same graph after removing every incoming edge to node 39, start 0, goal 39.
4. Weighted graph: 0→1 cost 8, 0→2 cost 2, 1→3 cost 2, 2→3 cost 9.

Expected behaviour
1. All three search algorithms return a route from 0 to 39.
2. All return [7] with depth zero.
3. All report no route.
4. Uniform-cost search chooses 0→1→3 with total cost 10 rather than 0→2→3 with cost 11.

Actual output
See proof.png in this folder. The program is deterministic; the graph is generated by the code and does not depend on an external dataset.
