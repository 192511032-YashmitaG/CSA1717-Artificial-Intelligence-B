TASK 5 – ASYMPTOTIC ANALYSIS

BFS: Θ(V+E) time for graph search and O(V) auxiliary graph-search storage in the general finite-graph implementation; in a tree representation the frontier can grow as Θ(b^d). It finds a minimum number-of-edges route when all moves have equal cost. As the hospital reaches one million locations, the queue/frontier can become the limiting resource.

Iterative DFS: Θ(V+E) worst-case time with a visited set and O(V) auxiliary storage for visited/parent plus stack. Its stack is usually narrower than BFS's queue, but it does not guarantee a shortest route. It can be a useful reachability search when memory is important and route optimality is not required.

Recursive IDDFS: Θ(b^d) time for a regular tree with b>1 and O(d) search-stack space (plus the graph and on-path bookkeeping). It repeats upper-level work but keeps the active recursion path small. It is suitable when the solution is expected to be shallow and memory is constrained.

The notation does not imply that one method is best for every hospital. BFS gives a shallowest route for equal step costs; DFS may use less frontier memory; IDDFS trades repeated work for low active search memory. The adjacency list itself still occupies O(V+E) memory. For non-uniform travel-time costs, uniform-cost search is the correct uninformed alternative for an optimal-cost route.
