TASK 2 – IDENTIFY THE BASIC OPERATION

Breadth-First Search
Basic operation: remove a location from the queue and inspect its outgoing edges (node expansion/successor generation). It occurs inside the main while loop. Each reachable vertex is expanded at most once with duplicate detection, and each outgoing edge is examined once. As the graph grows, the count grows with the number of reachable vertices and edges.

Iterative Depth-First Search
Basic operation: pop a location from the stack and inspect its neighbours. It occurs in the stack loop. With a visited structure, each vertex is pushed at most once and each edge is checked at most once. The number of operations depends strongly on the order in which the goal is encountered.

Recursive IDDFS
Basic operation: recursive call to depth-limited search, including the goal/limit tests. It occurs for each node reached at every depth limit. Shallow levels are revisited for successive limits, so the total call count is larger than a single DFS. For branching factor b and solution depth d, the repeated work is dominated by the deepest level for b > 1.

The operation count is more useful than timing alone because it describes how work grows with input size and is less affected by the computer used for testing.
