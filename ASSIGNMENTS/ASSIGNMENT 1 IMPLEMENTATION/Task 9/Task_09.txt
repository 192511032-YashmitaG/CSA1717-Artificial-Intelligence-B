TASK 9 – EXPERIMENTAL PERFORMANCE

Run: python Task_09/Task_09.py from the main assignment folder. The script generates the same deterministic branching-factor-3 tree for all algorithms at 1,000, 10,000, 100,000 and 1,000,000 locations. Each algorithm is run five times per size. The random seed is not applicable because the graph generator is deterministic.

Metrics recorded: generated nodes, expanded nodes, maximum frontier size, solution depth, path cost, optimality flag and mean execution time in milliseconds. Node and frontier counts are the primary evidence; time is secondary and depends on the machine.

The complete measurements are in performance_results.txt. The PNG files are plots generated from those measurements. The benchmark excludes graph-construction time from each algorithm's timer; graph construction is performed once per size and should be added when assessing a complete deployment pipeline.
